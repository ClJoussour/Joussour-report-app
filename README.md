# 🤖 تطبيق جسور المصغر (Jusoor Mini App)
**نظام أتمتة التقارير الخاص بنادي جسور - كلية العلوم الإسلامية**

## 📌 ما هذا المستودع؟
هذا المستودع يحتوي على الكود المصدري (HTML/JS/CSS) للتطبيق المصغر المدمج داخل منصة "تليجرام" (Telegram Web App). 
يُستخدم هذا التطبيق من قبل "المنشطين" لكتابة التقارير الميدانية بطريقة تفاعلية، ويقوم بإرسالها آلياً إلى مجموعة النادي عبر منصة Make.com.

---

## ⚙️ كيف يعمل النظام؟ (الهيكلة)
1. **الواجهة (Frontend):** ملف `index.html` الموجود هنا، وهو مستضاف مجاناً عبر `GitHub Pages`.
2. **الوسيط (The Bridge):** بوت التليجرام (`JusoorReport_bot`) المربوط بهذا الرابط عبر أوامر `BotFather`.
3. **العقل المدبر (Backend):** منصة `Make.com` التي تستقبل البيانات عبر (Webhook) وتقوم بتنسيقها وإرسالها كرسالة نصية.

---

## 🛠️ دليل المطورين (للأجيال القادمة في النادي)

### 1. كيف تعدل واجهة التطبيق؟
إذا أردت إضافة "خانة جديدة" (مثلاً: تقييم الحضور):
* قم بتعديل ملف `index.html` من هنا (GitHub).
* أضف الـ `<input>` الجديد في قسم الـ HTML.
* انزل لأسفل الكود (قسم الـ Javascript)، وأضف المتغير الجديد داخل قسم `const payload = { ... }`.
* **ملاحظة:** التعديلات ستظهر في التليجرام تلقائياً بعد 2-5 دقائق من الحفظ.

### 2. كيف تغير رابط الربط (Make.com Webhook)؟
إذا توقف حساب `Make.com` القديم، وأنشأتم حساباً جديداً:
1. استخرج رابط الـ Webhook الجديد.
2. افتح ملف `index.html` هنا للتعديل.
3. ابحث عن السطر: `const WEBHOOK_URL = 'https://hook.eu1.make.com/....';`
4. استبدل الرابط القديم بالجديد واضغط `Commit changes`.

### 3. كيف تعدل شكل "رسالة التليجرام" النهائية؟
شكل الرسالة (الأيقونات، الخط العريض) لا يوجد هنا في هذا الكود!
يجب عليك الدخول إلى حساب النادي في منصة **Make.com**، فتح السيناريو الخاص بالتقارير، والتعديل على دائرة (Telegram - Send a Text Message).
